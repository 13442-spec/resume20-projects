# 金融与办公提示词工具箱

**项目类型：个人项目**

在原金融行业提示词工具箱上扩展的个人项目。保留38个金融模块，新增29个模块，总计67个模块、32套场景组合。每套组合含准备材料、执行顺序与交付目标，可一键创建独立组。技术：HTML、CSS、JavaScript、localStorage。

## 30秒体验

1. 打开 index.html，在“具体任务，从组合开始”搜索任务。
2. 展开场景，确认材料、模块顺序和交付；点击“使用此组合（新建组）”。
3. 填写真实背景，预览完整指令，复制并打开模型后自行粘贴发送。

工具只在本地组装和保存指令，实际发送由用户在模型页面完成。音频需交给支持音频的模型或先提供转写稿；图表需在支持代码执行的环境运行。提示词明确要求标注未运行代码与待复核账单，模型输出仍须人工检查。实际财务、合同及人事决定由授权人员复核。

## 具体场景与组合

### 01 财务 · 收支流水生成客户账单

- 准备材料：收支流水、期间币种、客户项目、科目表、已付款记录
- 执行顺序：会计记账与账单生成 → 账单输出与勾稽 → 交付核验
- 交付：账单明细、汇总CSV、差异及会计复核清单

### 02 财务 · 发票报销审核与记账草稿

- 准备材料：发票识别文本、付款记录、报销制度与科目表
- 执行顺序：发票与报销单据核验 → 会计记账与账单生成 → 交付核验
- 交付：补件清单、重复疑点、凭证草稿

### 03 财务 · 银行流水与账簿月末对账

- 准备材料：银行流水与账簿、期间、唯一键、币种
- 执行顺序：数据清洗规则与质量报告 → 对账差异分类与排查 → 交付核验
- 交付：匹配记录、未达账项与金额核对
