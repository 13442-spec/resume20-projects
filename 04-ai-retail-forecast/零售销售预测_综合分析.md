# 题目B第五步：描述性分析、影响因素关联与时间序列预测

## 1. 分析范围

本阶段全部读取第四步生成的标准分析表，不再直接读取或修改原始 data.csv。月度预测目标严格定义为按 Order Date 聚合的月度 Sales 总额；模型训练期为2022—2024，最终测试期为2025。

## 2. 描述性分析结论

### 2.1 趋势与季节性

- 2022年销售额为 $479,856.21，2025年为 $722,052.02，同期增长 50.47%；月度表按年度聚合与明细表重新聚合的最大差异为0。
- 11月平均销售额最高，为 $87,540.43；2月最低，为 $14,842.78；峰谷月均销售比为 5.90。峰月和谷月均附有95% t置信区间。
- 月度索引覆盖2022-01至2025-12共48个月，没有缺月。

### 2.2 品类、区域和客户结构

- Technology销售额 $827,455.87，占总销售 36.59%，为最高品类。
- West销售额 $710,219.68，占总销售 31.40%，为最高区域。
- 观察期内793个客户中780个至少有2个分析订单，观察期复购率为 98.36%，复购客户贡献 99.77% 销售额。该指标是四年观察窗内的复购，不等同于90天或年度复购率。

上述结论均写入 outputs/analysis/descriptive/descriptive_findings.json，并由独立明细重新聚合核验。

## 3. 影响因素关联分析

以分析订单金额为结果变量，对 Segment、Region、Ship Mode 做探索性关联分析：

- 订单金额长尾明显，因此每个维度以Kruskal-Wallis检验为主，同时报告epsilon平方效应量；
- 高低组差异另报告Bootstrap中位数差异95%区间和Cohen's d；
- 补充模型为 log1p(order_sales) ~ segment + region + ship_mode，采用HC3稳健标准误，系数p值用Holm方法校正。

结果显示：Segment、Region和Ship Mode的总体组间效应量均接近0；Region的高低组中位数差异Bootstrap区间跨过0，不能据此作稳定经营因果判断。调整模型R²约为0.003，说明这些订单维度对单笔订单金额的解释力很有限。完整数值、区间和系数见 outputs/analysis/impact/。

本分析只支持“关联”措辞，不能写成某个区域、配送方式或客户类型“导致”销售变化。客户重复出现、时间趋势、品类组合、促销和未观测变量均可能造成混杂。

## 4. 时间序列模型与验证

候选模型按预先规定顺序比较：

1. Last Value；
2. Seasonal Naive（12个月季节滞后）；
3. 趋势+月份虚拟变量回归；
4. 加性ETS（加性趋势、阻尼趋势、12个月季节项）；
5. SARIMA(1,1,1)×(0,1,1,12)。

模型选择只使用训练期内两个时间顺序滚动折：前24个月预测后6个月、前30个月预测后6个月。平均MAE最低的是SARIMA，因而用2022—2025全部48个月重新拟合后生成2026预测。2025测试结果仍完整保留所有候选模型，便于检查模型选择与真实未来表现的差异。

2025测试期主要结果：

- Seasonal Naive：MAE $15,444.18，MAPE 24.86%；
- 趋势+月份回归：MAE $10,839.52，MAPE 17.52%；
- ETS：MAE $10,563.34，MAPE 18.11%；
- SARIMA：MAE $13,555.97，MAPE 27.22%。

因此，SARIMA在训练期滚动验证中胜出，但在2025最终测试中ETS的MAE更低。这一差异已经保留在模型对比表中，不能只报告有利于所选模型的数字。SARIMA仍优于Seasonal Naive的2025 MAE，但预测结果应保留模型不确定性。

## 5. 2026预测

选定SARIMA生成的2026全年点预测为 $869,577.30。输出包括：

- 2026月度点预测及80%/95%区间；
- 2026季度汇总及区间；
- 2026全年汇总及区间。

当前区间为SARIMAX模型置信区间并截断到非负值；季度和年度区间通过月度区间端点求和，属于保守汇总而非严格的联合预测区间。无外生变量时，2026是历史趋势和季节性的外推，未来订单数、客户数、品类份额等未知变量没有直接作为已知特征。
